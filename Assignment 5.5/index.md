# Assignment 5.5 - CSS Fundamentals Mini-Project

## Design Choices

1. I used one external stylesheet, style.css, linked from all four pages, so every page has the same look and the CSS is written only once.
2. I chose a blue and orange palette. Dark blue is used for the header, footer, headings and table headers, and orange is used for hover effects.
3. The colors, spacing and font are stored as CSS variables in :root, so I can change the whole design by editing one value.
4. The navigation links look like buttons and change color on hover, and the tables have a dark header and alternate row colors to make them easy to read.
5. The form fields have labels, padding, borders and a highlighted focus outline, and the Register button uses a reusable .btn class.
